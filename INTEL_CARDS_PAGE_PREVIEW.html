Three-Level Navigation System

Level 1 - Intel Type Selection:

  • User taps "Get The Edge" from bet selection page
  • Presented with grid of available intel types (Injury, Analytics, Betting, etc.)
  • Only shows types that have available data for this game
  • Each tile shows preview stats (e.g., injury counts)
  • User selects which intel type they want (e.g., taps "Injury Intel")

Level 2 - Team Purchase Options:

  • After selecting intel type, user sees 3 purchase options
  • Team A Card - 30 BR (Lakers only)
  • Team B Card - 30 BR (Warriors only)
  • Bundle Card - 50 BR (Both teams, save 10 BR)
  • Each card shows preview of what's included
  • Bundle highlighted as best value
  • User selects and purchases one option

Level 3 - Injury Report View:

  • After purchase, user immediately sees full injury report
  • Shows "Owned" badge confirming purchase
  • Displays detailed injury information for purchased team(s)
  • For each injured player: Status badge, injury type/location, expected return, ESPN commentary
  • Intel Insight section: Game impact analysis, injury impact scores, betting recommendations
  • Report is saved and accessible anytime before game starts

Use Cases:

  • Betting on Lakers player props → Buy Lakers card only (30 BR) → See Lakers injuries
  • Betting on Warriors ML → Buy Warriors card only (30 BR) → See Warriors injuries
  • Betting on game total/spread → Buy bundle (50 BR) → See both teams + comparison
  • Want maximum intel → Buy bundle (50 BR) → Get complete injury intel + impact analysis
