✅ Card Display Strategy
ON CARD: Title (2 lines max) + Description (3 lines max) + Source + Time
INTERACTION: Tap "Read More" → Open full article in browser or dedicated detail page
Option 1: Open in Browser (Simpler)
  • Tap "Read More" → Launch article URL in default browser
  • ✅ Pros: No extra UI needed, user gets full article formatting
  • ❌ Cons: Leaves app, may have ads/paywalls
Option 2: Dedicated Detail Page (Better UX)
  • Tap card → Navigate to NewsDetailScreen with full content
  • ✅ Pros: Stays in app, consistent theming, can add actions (share, save)
  • ❌ Cons: Need to build detail screen, content may be truncated by API
🎯 Recommended Approach
Use Option 1 for MVP: Open article URL in browser when user taps card or "Read More" button. The NewsAPI description (81-132 chars) provides enough context for users to decide if they want to read more.
