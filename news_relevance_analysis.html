STEP 2
🎯 Relevance Scoring Algorithm

Each article is scored from 0.0 to 1.0 based on:

Check Points Added Logic
Home Team Mentioned +0.5 Article title/description contains team name
Away Team Mentioned +0.5 Article title/description contains team name
Per Relevant Keyword +0.2 each injury, doubtful, questionable, probable, starting, lineup, suspension, return
// news_api_service.dart - lines 130-160 double relevance = 0.0; // Check team mentions if (text.contains(homeNorm)) { relevance += 0.5; mentions.add(homeTeam); } if (text.contains(awayNorm)) { relevance += 0.5; mentions.add(awayTeam); } // Check for relevant keywords final keywords = ['injury', 'doubtful', 'questionable', 'probable', 'starting', 'lineup', 'suspension', 'return']; for (final keyword in keywords) { if (text.contains(keyword)) { relevance += 0.2; } } return relevance.clamp(0.0, 1.0);

STEP 4
🚑 Injury Detection & Impact Assessment

Injury Keywords:

injury, injured, hurt, doubtful, questionable, probable, game-time decision, sidelined, out

Impact Level Assessment:

If Article Contains... Impact Level Reasoning
"out" OR "ruled out" High Player definitely not playing
"doubtful" High 75% chance they won't play
"questionable" Medium 50/50 chance of playing
"probable" OR "game-time" Low Likely to play but watch pregame
None of the above Unknown Unclear status
// news_api_service.dart - lines 201-214 if (text.contains('out') || text.contains('ruled out')) { return 'high'; } else if (text.contains('doubtful')) { return 'high'; } else if (text.contains('questionable')) { return 'medium'; } else if (text.contains('probable') || text.contains('game-time')) { return 'low'; }

⚠️ Current Limitations

  1. No Date Filtering: Gets articles from any time period (should limit to 14 days)
  2. Simple Keyword Matching: Could miss context (e.g., "not injured" vs "injured")
  3. No Player Name Recognition: Doesn't boost relevance for star players like LeBron
  4. Fixed Threshold: 0.5 relevance might be too strict or too lenient
  5. No Source Credibility Weighting: ESPN article = random blog article

✅ Strengths

  1. Multi-Source: Checks ESPN, CBS Sports, Bleacher Report, Fox Sports
  2. Injury Focus: Specialized detection for injury news (critical for betting)
  3. Sentiment Scoring: Helps users gauge team morale/momentum
  4. Topic Clustering: Groups related news for easier consumption
  5. Relevance Filtering: Removes low-quality/unrelated articles
