## 6. HOW TO PLAY

### 6.1 Making Picks
1. Browse available pools for upcoming games/events
2. Select a pool and pay the BR entry fee
3. Make your predictions for each game in the pool:
   - Select winning team/fighter
   - (Optional) Set confidence level (1-5 stars)
   - (Optional for premium) View real-time odds
4. Submit your picks before pool closes (typically 15 minutes before event start)

### 6.2 Scoring System

**Free Tier - Simple Scoring:**
- **Correct pick:** 1.0 base points
- **Confidence multiplier:** 0.9x (1 star) to 1.3x (5 stars)
- **Underdog bonus:** Based on team/fighter record differential
  - Formula: `max(0, (opponent_wins - team_wins) / 20)`
  - Example: Picking 3-7 team over 8-2 team = +0.25 bonus

**Premium Tier - Odds-Based Scoring:**
- **Correct pick:** 1.0 base points
- **Confidence multiplier:** 0.9x (1 star) to 1.3x (5 stars)
- **Underdog bonus:** Based on real Vegas odds
  - Formula: `picked_odds / 400` (for positive odds)
  - Example: Picking +200 underdog = +0.50 bonus
  - Example: Picking -150 favorite = no bonus

### 6.3 Ranking and Leaderboards
- Users are ranked by total score within each competition period
- Tiebreakers (in order):
  1. Highest score
  2. Fewest total picks (efficiency)
  3. Earliest submission timestamp
  4. Random draw (if still tied)
